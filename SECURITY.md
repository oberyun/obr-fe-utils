# Security Policy

## Supported Versions

This project is actively maintained only on the latest released version and the current `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| `main` branch | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** report it through public GitHub issues or discussions.

Instead, please report it privately by email:

**liuxiangqing@bjober.com.cn**

Please include the following information in your report if possible:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Affected version(s)
- Potential impact
- Suggested fix or mitigation, if available

## Response Process

After receiving a valid vulnerability report, I will make a best effort to:

- Acknowledge receipt within **7 days**
- Investigate and validate the issue
- Prepare a fix or mitigation if confirmed
- Publish a patch in a reasonable timeframe

I appreciate responsible disclosure and will handle valid reports as promptly as possible.
